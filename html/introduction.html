What is Python?

Python is a high-level programming language created by Guido van Rossum and first released in 1991. It was designed to be readable, practical, and enjoyable to use.

Python programs are written as plain text files with the .py extension. A programmer writes instructions, then the Python interpreter reads those instructions and runs them on the computer.

Interpreted

A Python interpreter executes your program’s instructions.

High-Level

It hides many low-level computer details, making programs easier to write.

Dynamically Typed

You do not need to declare a variable type before using it.

Readable Syntax

Python code often looks close to plain English.

How a Python Program Runs

1

Write

The programmer writes Python statements in a code editor.

2

Save

The file is saved with a clear name, such as hello.py.

3

Run

The Python interpreter executes the file and shows the result.

4

Debug

If there is an error, the programmer reads the message and corrects the code.

Where Python is Used

Web Development

Python can power websites and web applications.

Data Science

It helps analyze data and create charts or reports.

Automation

Python scripts can perform repetitive computer tasks.

Artificial Intelligence

Many AI and machine learning tools support Python.

Set Up Python

Install a supported Python 3 release from python.org/downloads. Choose the instructions for your operating system.

  1. Windows: install the Python install manager from python.org, then open a new terminal and run python --version. If you use a traditional installer with an “Add Python to PATH” option, enable it.
  2. macOS: run the Python installer package, follow its instructions, and open Terminal to check python3 --version.
  3. Linux: check python3 --version first. If Python is missing, install Python 3 using your distribution’s package manager.
  4. Open an editor such as IDLE or Visual Studio Code. Save your first program as hello.py, then run python hello.py on Windows or python3 hello.py on macOS/Linux from the same folder.
What is PATH? It is a list of folders your computer searches when you type a command. Reopen your terminal after installation so it can pick up any changes.

Official setup guides: Windows · macOS · Linux / Unix.

Your First Program
