Defining a Function

The def keyword creates a function. Parameters receive input values, and return sends a result back.

Function Name

The name used to call the function later, such as square.

Parameter

A variable listed inside the brackets that receives an input value.

Return Value

The result sent back from the function to the main program.

function.py
def square(number):
    return number * number

answer = square(5)
print(answer)
Output:
25
Why functions matter: A function avoids repeated code. Once it is written, it can be called many times with different inputs.

Default and Keyword Arguments

A default argument gives a parameter a value automatically if no value is provided. A keyword argument uses the parameter name, which can make code easier to read.

arguments.py
def greet(name, message="Welcome"):
    print(message, name)

greet("Ravi")
greet(name="Mina", message="Hello")
Output:
Welcome Ravi
Hello Mina

Importing Modules

A module organizes related Python code. Python’s standard library includes useful modules you can import without installing extra packages.

math

import math gives mathematical functions like math.sqrt(16).

random

import random can choose random numbers using random.randint(1, 6).

datetime

from datetime import date can get dates using date.today().

modules.py
import math
from datetime import date

print(math.sqrt(16))
print(date.today())
Output:
4.0
Today’s date in YYYY-MM-DD format
Note: The date output changes depending on the day the program is run.

Function Practice Example

The example below shows how a small function can receive two marks and return the total.

add_marks.py
def add_marks(maths, english):
    return maths + english

total = add_marks(78, 84)
print(total)
Output:
162

Practice Task

Build on the example: create a function named average_marks that accepts two marks and returns their average. Try it with 78 and 84; the result should be 81.0.
