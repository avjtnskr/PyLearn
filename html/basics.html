Variables

A variable is a name that refers to a value. In Python, you create one by assigning a value with the equals sign.

The value on the right side is stored in the variable name on the left side. If a new value is assigned later, the old value is replaced.

  • Variable names can contain letters, numbers, and underscores.
  • They cannot start with a number.
  • Use meaningful names such as student_name or total_marks.
  • Python variable names are case-sensitive, so marks and Marks are different.
  • Names cannot be Python keywords such as if, for, or class.
variables.py
name = "Asha"
age = 16
print(name)
print(age)
Output:
Asha
16
Common mistake: Do not put quotation marks around a variable name when you want its value. print(age) prints the value, but print("age") prints the word age.

Data Types

Operators

Operators perform calculations and comparisons.

They are often used in expressions. An expression is a piece of code that produces a value, such as 10 + 3 or marks >= 50.

Type Conversion

Type conversion changes a value from one data type to another.

The input() function always returns a string. Convert it to a number before doing arithmetic.

conversion.py
marks = "85"
total = int(marks) + 10
print(total)
Output:
95
Remember: int("85") works because the string contains digits, but int("eighty five") would cause an error.
