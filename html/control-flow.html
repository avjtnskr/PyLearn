Making Decisions: if / elif / else

Control flow makes a program flexible. Without it, Python would simply run every line from top to bottom with no decisions or repetition.

if, elif, and else allow Python to choose between different actions.

Python uses indentation to show which statements belong inside each condition. The indented lines run only when their condition is true.

if_else.py
marks = 82
if marks >= 90:
    print("Excellent")
elif marks >= 50:
    print("Pass")
else:
    print("Try again")
Output:
Pass

Repeating with a for Loop

A loop repeats code. The range() function is commonly used with a for loop.

In range(1, 4), the starting value is included, but the stopping value is not included.

for_loop.py
for number in range(1, 4):
    print(number)
Output:
1
2
3

Repeating with a while Loop

A while loop runs as long as a condition is true.

It is useful when you do not know in advance exactly how many times the loop should run.

while_loop.py
count = 1
while count <= 3:
    print(count)
    count += 1
Output:
1
2
3
Common mistake: Forgetting to update the loop variable can create an infinite loop that never stops.

break and continue

break stops a loop. continue skips the current repetition and moves to the next one.

break_continue.py
for n in range(1, 6):
    if n == 3:
        continue
    if n == 5:
        break
    print(n)
Output:
1
2
4

Nested Loops

A nested loop is a loop inside another loop.

The inner loop completes all of its repetitions for each single repetition of the outer loop.

nested_loops.py
for row in range(1, 3):
    for col in range(1, 3):
        print(row, col)
Output:
1 1
1 2
2 1
2 2
