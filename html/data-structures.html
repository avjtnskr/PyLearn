Lists

A list is ordered, changeable, and allows duplicate values.

Use a list when you need to store several related values and may need to add, remove, or update items later.

lists.py
fruits = ["apple", "banana", "mango"]
print(fruits[0])
print(fruits[1:3])
fruits.append("orange")
Output:
apple
['banana', 'mango']
  • append() adds an item at the end.
  • remove() removes a matching item.
  • len() counts how many items are in the list.

Tuples

A tuple is ordered and immutable: you cannot replace, add, or remove its items after creation.

Tuples are useful for values that should stay fixed, such as RGB color values or coordinates.

tuples.py
coordinates = (10, 20)
print(coordinates[0])
Output:
10

Dictionaries

A dictionary stores data as key-value pairs.

Each key works like a label. This makes dictionaries useful for records, profiles, and settings.

dictionaries.py
student = {"name": "Asha", "age": 16}
print(student["name"])
student["grade"] = "A"
Output:
Asha
  • keys() returns all keys.
  • values() returns all values.
  • get() safely reads a value by key.

Sets

A set stores unique values and supports operations such as union and intersection.

Sets are helpful when duplicates should be removed automatically.

sets.py
a = {1, 2, 3}
b = {3, 4, 5}
print(a.union(b))
print(a.intersection(b))
Output:
{1, 2, 3, 4, 5}
{3}
Set order can vary: sets are unordered, so Python may display these values in a different order. The values in the result are what matter.
